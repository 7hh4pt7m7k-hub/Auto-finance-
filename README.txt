АвтоФинансы v2.1 — PWA для iPhone.

Файлы:
- index.html — приложение
- manifest.json — описание PWA
- sw.js — офлайн-кэш
- icon-192.png / icon-512.png — иконки

Публикация:
1. Создайте GitHub repository (Public).
2. Загрузите все эти файлы в корень repository.
3. Settings → Pages → Deploy from a branch → main → /root → Save.
4. Откройте выданный HTTPS-адрес в Safari.
5. Поделиться → На экран «Домой» → Добавить.

После первого открытия приложение сможет работать без интернета, а данные расходов остаются в localStorage браузера.
